How Policy Lens Works

A Retrieval-Augmented Generation (RAG) pipeline grounded entirely in hospital policy documents.

Evaluation

Policy Lens is evaluated using a curated set of supported, paraphrased, and unsupported policy questions.

Evaluation Categories

Supported Questions

Questions whose answers exist directly in the indexed policy documents. Policy Lens should retrieve relevant evidence and generate a grounded answer.

Paraphrased Questions

Questions that express the same policy request using different wording or phrasing. Tests semantic retrieval robustness via the embedding component.

Unsupported Questions

Questions whose answers do not exist in the policy documents (e.g. medical advice). Policy Lens should correctly trigger the insufficient-evidence response.

About Evaluation Metrics

Retrieval accuracy, supported/unsupported question rates, and answer quality scores require a labeled evaluation dataset with ground-truth question–answer pairs. These metrics are reported when an evaluation run is executed against the live system. The retrieval parameters shown above reflect the live system configuration.
